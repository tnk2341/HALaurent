## ⚡ Особенности и преимущества

- **Постоянное TCP-соединение (порт 2424, Local Push):** Не нагружает контроллер бесконечным HTTP-опросом. Все события от дискретных входов и считывателей поступают в Home Assistant мгновенно с точностью до миллисекунд.
- **Поддержка нескольких устройств:** Можно подключить неограниченное количество контроллеров Laurent в одной системе (каждый с индивидуальными IP, портами и настройками).
- **СКУД и Wiegand (Laurent-4):**
  - Поддержка до 4 считывателей Wiegand и 1-Wire iButton (DS1990).
  - Встроенный декодер UID с поддержкой **реверса байтов (Little-Endian / Big-Endian)**, полностью совместимый с популярным веб- и JS-парсером (`hexToUid`).
  - Передача событий поднесения карт в сущности `event` и общую шину событий `laurent_wiegand_event`.
- **Любые типы датчиков:**
  - Входные дискретные опторазвязанные линии (`binary_sensor`).
  - Аналогово-цифровые преобразователи АЦП (`sensor` в Вольтах) для любых аналоговых датчиков давления, уровня, тока.
  - Цифровые датчики температуры 1-Wire DS18B20 (`sensor` в °C).
  - Аппаратные счетчики импульсов на входах (`sensor`) для учета расхода и проверки дребезга.
- **Управление нагрузками:**
  - Реле (`switch`) с сохранением актуального статуса.
  - Импульсные кнопки (`button`) для кратковременного открывания электрозамков и шлагбаумов.
- **Устойчивость к сбоям:** Автоматический reconnect с экспоненциальной задержкой при перезагрузке контроллера или сети, плюс сенсор диагностики соединения.

## 📦 Установка

### Способ 1: Через HACS (Рекомендуемый)
1. Откройте **HACS** в Home Assistant -> **Интеграции**.
2. В правом верхнем углу нажмите меню с тремя точками -> **Пользовательские репозитории** (Custom repositories).
3. В поле **Репозиторий** вставьте ссылку на данный репозиторий.
4. В поле **Тип** выберите **Интеграция** (Integration) и нажмите **Добавить**.
5. Найдите **KernelChip Laurent** в списке и нажмите **Установить**.
6. Перезапустите Home Assistant.

### Способ 2: Ручная установка
1. Скопируйте папку `custom_components/laurent/` в директорию `custom_components/` вашей конфигурации Home Assistant.
2. Перезапустите Home Assistant.

## ⚙️ Настройка

1. В Home Assistant перейдите в **Настройки** -> **Устройства и службы** -> **Добавить интеграцию**.
2. В поиске введите **Laurent** (или **KernelChip Laurent**).
3. Заполните форму:
   - **IP-адрес контроллера:** например, `192.168.0.101`
   - **TCP-порт:** по умолчанию `2424`
   - **Пароль:** по умолчанию `Laurent`
   - **Имя устройства:** например, `Laurent СКУД Вход`
   - **Реверс байтов UID считывателей Wiegand:** `Включено` (по умолчанию)
4. Нажмите **Отправить**. Интеграция протестирует сокет, определит модель контроллера и создаст все сущности.

## 📊 Диагностика дребезга контактов и графики

Благодаря тому, что интеграция транслирует события фронтов сигналов напрямую в шину событий `laurent_input_changed`, а также собирает счетчики импульсов `sensor.<name>_counter_X`, вы можете легко отслеживать дребезг контактов кнопок и концевиков:

### Пример графика счетчиков импульсов в Lovelace:
```yaml
type: history-graph
title: Анализ импульсов и дребезга
hours_to_show: 24
entities:
  - entity: sensor.laurent_counter_1
    name: Счетчик импульсов Вход 1
  - entity: binary_sensor.laurent_input_1
    name: Состояние Входа 1
```

## 🔑 Автоматизация СКУД по Wiegand UID

Когда к любому считывателю подносится карточка, интеграция отправляет событие `laurent_wiegand_event`. Пример автоматизации для открытия замка:

```yaml
alias: "Открытие двери по карте доступа"
trigger:
  - platform: event
    event_type: laurent_wiegand_event
condition:
  - condition: template
    value_template: "{{ trigger.event.data.formatted_uid == '78BF529E00000000' }}"
action:
  - service: button.press
    target:
      entity_id: button.laurent_open_door_pulse_relay_1
  - service: logbook.log
    data:
      name: "СКУД"
      message: "Дверь открыта по карте: {{ trigger.event.data.formatted_uid }}"
```

## 🛠 Поддерживаемые модели

- **Laurent-4:** 4 реле, 4 дискретных входа, 4 Wiegand считывателя, 1-Wire iButton.
- **Laurent-5 / 5G:** 4 реле, до 6 дискретных входов, 4 канала АЦП, 1-Wire термодатчики, ШИМ.
- **Laurent-2, Laurent-128:** Релейные модули расширения и универсальные контроллеры KernelChip.
